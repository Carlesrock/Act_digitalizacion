# 2K - Digitalización aplicada al sistema productivo

La asignatura digitalización aplicada al sistema productivo
trata como funciona la transformación dentro de una empresa, tano 
para la parte informática(IT) como la industrial (OT)

Es una assignatura pensada para entender como las tecnologías
actuales canvian la forma de producir,decidir  y trebajar en 
cualquier sector productivo


## Unidades a trabajar

- Unitat 1 : Digitalizació en els sistemes productius

    * Què és digitalitzar una empresa
    * Diférencia entre informática(IT) i  operació industrial(OT)
    * Per què és important integrar ambos mons


- Unitat 2 : Tecnologies Habilitadores Digitals(THD)

    * IOT (Internet of things)
    * Big Data
    * 5G
    * Robòtica col·laborativa
    * Blockchain
    * Realitat virtual
    * Impressió 3D
    * Gemelos digitales
    * Avantages,riscos i aplicacions reals


- Unitat 3 : Computació al núvol

    * Cloud computing
    * Edge,Fog i Mist computing
    * On estan realment les dades?

- Unitat 4: Intel·ligència Artificial (IA)
    * IA per automatizar, optimizar i analitzar
    * Aplicacions reals en empreses
    * Oportunitats i reptes per a treballadors i organitzacions

- Big Data i Ciberseguretat

    * Valor dels dades en una empresa
    * Machine learning i deep learning
    * Estratègies de protecció
    * Què passa quan roben o cifren dades?

- Projecte de Transformació Digital
    * Analitzar una empresa


    * Detectar necessitats


    * Proposar tecnologies


    * Planificar costos, beneficis i temporalització
